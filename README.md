# Mizzz Bloxxxxx — Battle Mode

Концепция
--
Ты пришёл на экзамен к С.В.М. (инициалы). Чтобы получить 100 баллов, профессор предложил необычное условие: сыграть с ним в игру. Ты — слева, босс (профессор) — справа. Победи босса в битве паззлов, чтобы сдать экзамен.

О проекте
--
Mizzz Bloxxxxx — классическая игра «3 в ряд» с интересными дополнениями, реализованная на Python с использованием Pygame. Игра поддерживает внешний набор графики и звуков в папке `data/` (блоки, фон, эффекты и музыка). Если файлов нет — игра всё равно запустится, но без дополнительных графических и звуковых эффектов.

Управление
--
- Мышь: выбор и обмен блоков — кликните по блоку, затем по соседнему, чтобы поменять местами.
- `Esc`: выйти из игры.
- `T`: переключатель подсказки/режима (если реализовано в сборке).

Установка
--
1. Установите Python 3.9+.
2. Установите зависимости:

```bash
pip install pygame numpy
```

Запуск
--
В каталоге проекта выполните:

```bash
python main.py
```

Папка `data/` (опционально)
--
Поместите в `data/` ресурсы для улучшенного внешнего вида и звуков:
- `block1.png` … `block8.png` — изображения символов/иконок для типов блоков (заменяют однотонные квадраты).
- `background.png` — фоновое изображение.
- `graphic.png` — графика над игровым полем (логотип/баннер).
- `sound1.wav` … `sound4.wav` — звуковые эффекты для матчей.
- `hello.wav`, `tschuess.wav`, `hilfe.wav` — дополнительные звуки (старт/выход/помощь).
- Любые `.mp3` файлы проигрываются как фоновые композиции (игра создаст плейлист автоматически).
- Файл `farben.txt` (пустой) — если присутствует, игра будет отображать цветной фон позади блоков.

Рекомендации по графике
--
- Блочные изображения должны быть квадратными и иметь прозрачный фон (альфа-канал), размер произвольный — игра масштабирует их до размера клетки.

Концепция геймплея
--
Игровое поле — сетка 10×10. Сложите последовательность из трёх и более одинаковых символов по горизонтали или вертикали, чтобы нанести урон боссу. Некоторые комбинации дают больше урона (4/5 и более). Следите за таймером/счётом и используйте подсказки, чтобы выжать максимум из хода — вам нужно победить босса, чтобы «сдать экзамен».

Настройки и параметры
--
В коде присутствуют параметры для плавной/быстрой масштабировки, отображения границ и управления музыкой. Можно запустить с опциями командной строки (см. `-h`):

```bash
python mizzz_bloxxxx_v3.py -h
```

Лицензия и кредиты
--
Проект основан на разработках пользователя `zeittresor` и использовал разные инструменты генерации контента. Все дополнительные треки/графика из `data/` добавляются пользователем самостоятельно — убедитесь в наличии прав на использование.
